# Cloudflare Config Hub — راهنمای فارسی

پلتفرم جامع و ماژولار مدیریت، اسکن واقعی، رتبه‌بندی هوشمند و ساخت کانفیگ‌های شبکه از طریق **ربات تلگرام**، **مینی‌اپ تلگرام (پشتیبانی کامل فارسی RTL)** و **پنل ادمین وب**.

## اصول مهندسی پلتفرم
- **شفافیت کامل در وضعیت تست:** هیچ آی‌پی یا اندپوینت تست‌نشده‌ای سالم معرفی نمی‌شود و نتایج تست هرگز جعلی تولید نمی‌شوند.
- **الگوریتم ۷ مرحله‌ای انتخاب IP:** ترکیب نرخ موفقیت، تاخیر، پایداری، Jitter، سازگاری پروتکل و سابقه تاریخی (کاندیدای پایدار بر کاندیدای ناپایدار کم‌تاخیر اولویت دارد).
- **پشتیبانی تفکیک‌شده پروتکل‌ها:** WireGuard، Cloudflare WARP، MASQUE (RFC 9298)، VLESS و Trojan با اعتبارسنجی دقیق پارامترها و تولید QR.
- **امنیت پیشرفته:** جلوگیری از SSRF، اعتبارسنجی رسمی HMAC مینی‌اپ تلگرام، رمزنگاری توکن Cloudflare، سطوح دسترسی RBAC و حذف خودکار اسرار از لاگ‌ها.

## راه‌اندازی سریع با Docker
```bash
cp .env.example .env
docker compose up -d --build
```
